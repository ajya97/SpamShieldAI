REST API reference

Integrate spam detection directly into your own applications using two simple, stable endpoints. No authentication is required for either.

POST /api/predict

Submit email text as JSON and receive a prediction with a confidence score.

Request headers 
Content-Type: application/json
Example request 
{
  "email_text": "Congratulations! You have won..."
}
Example response (illustrative only) 
{
  "success": true,
  "prediction": "Spam",
  "confidence": 0.94
}
Error response (e.g. missing field) 
{
  "success": false,
  "error": "email_text is required"
}
cURL example 
curl -X POST https://your-domain.com/api/predict \
  -H "Content-Type: application/json" \
  -d '{"email_text": "Congratulations! You have won..."}'
GET /api/health

Check whether the API service is currently operational — useful for uptime monitors.

Example response 
{
  "status": "healthy",
  "service": "Spam email Detector API"
}
Live status: Checking…
cURL example 
curl https://your-domain.com/api/health

Response values above under "Example response" are illustrative only and do not represent an actual prediction. The live status pill reflects the real, current result of /api/health.
